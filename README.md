## The entry

> The email you didn't read already decided this.

One sentence, 47 characters. The decision the meeting was called to make
already exists, it was already communicated, and the room's own negligence
is why they are sitting there. Nothing left to discuss, no one left to
blame but themselves. It doesn't describe the meeting or joke about
meetings — it ends it.

## How it works

`main.py` (Python 3, standard library only) scores five candidate lines on
kill-completeness and relatability, picks the highest scorer, and writes
exactly that one sentence (no trailing newline) to `/output/entry.txt`. It
self-checks the gate: 1–200 characters, not only whitespace.

```sh
python3 main.py   # writes /output/entry.txt
```
